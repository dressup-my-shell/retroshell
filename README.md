# retroshell

A synthwave-inspired terminal prompt with neon colors and retro 80s vibes. Turn your terminal into a time machine.

## Install

```bash
npm install -g retroshell
```

## Usage

```bash
# Show the ASCII banner
retroshell banner

# Get the PS1 string for your shell
retroshell ps1

# Print install instructions
retroshell install
```

## Add to your shell

Add this line to your `.bashrc` or `.zshrc`:

```bash
eval "$(npx retroshell ps1)"
```
